Built an AI-Powered Multilingual Translator Chatbot with Aliza Javed, an incredibly talented and hardworking partner who brought exceptional dedication to every aspect of this project. Under the guidance of Professor Madiha, we created one of my most complete full-stack Python projects to date.



This isn't just a translation tool. It's a fully integrated language assistant that combines LLM intelligence, real-time voice input/output, and a polished glassmorphism UI into one seamless experience.



Tech and Integration

Powered by Claude (Anthropic's LLM) via REST API, the app doesn't rely on simple dictionary lookups. It understands context, which means it correctly handles idioms, metaphors, and culturally nuanced phrases that traditional translators often get wrong. The AI is prompted to return natural, accurate translations rather than literal word-for-word conversions.



Key Features



Translate between any two languages freely. Set your source and target language without restrictions.



Metaphor and idiom intelligence. The LLM understands figures of speech and returns their true meaning in the target language, not a broken literal translation.



Voice input. Speak your text directly into the app. Speech is recognized, transcribed, and sent to the AI for translation automatically.



Auto text-to-speech. The app reads both your input and the AI's translation aloud. This can be toggled on or off at any time.



Save AI voice output. Export the AI's spoken translation as an audio file for later use.



Translation history log. Every session is logged so you can scroll back through past translations without losing context.



Dark and light theme toggle. Switch between a deep navy glassmorphism dark mode and a clean frosted light mode instantly.



Glassmorphism UI. Built entirely in Python with Tkinter, using layered frames, rounded canvases, and a blue crystal color palette to simulate the glass effect without any external UI libraries.



Threaded architecture. API calls run on background threads so the UI never freezes during translation.
